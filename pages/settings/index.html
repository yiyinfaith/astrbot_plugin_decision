Tools 与 SubAgents

决定 Jev 如何筛选能力，以及主 LLM 能看到哪些候选。

过滤普通 Tools开启后调用 Jev 并只保留 Jev 判断通过的普通 Tool；关闭后普通 Tool 全量保留。
过滤 SubAgents开启后调用 Jev 并只保留 Jev 判断通过的 SubAgent；关闭后 SubAgent 全量保留。

Jev 分数达到此值才会推荐；数值越高越严格。默认 0.65，适合减少无关候选。

判断范围：先在 AstrBot 原生配置页保持“Tools/SubAgent 决策”总开关开启。两项过滤都关闭时不请求 Jev，Tools 与 SubAgents 全量保留，推荐提示词只包含手动勾选“推荐给主 LLM”的项目；只开一项时，Jev 只判断对应类别，另一类别全量保留且只使用手动推荐；两项都开时才同时判断 Tools 与 SubAgents。
