# jev决策综合插件

<p align="center"><img src="https://raw.githubusercontent.com/yiyinfaith/astrbot_plugin_decision/main/logo.png" alt="Decision Logo" width="160" height="160" /></p>

AstrBot 的 JEV 决策插件：在请求交给主 LLM 前，用 AstrBot 原生 Decision/Jev Provider 逐项判断本次需要哪些 Tool、MCP、Skill 和 SubAgent；同时提供消息接话、虚拟生活主动发起、aigen 拍照/拍视频/生音频、人际网络和多模态理解。最终回答、工具执行和人格仍由 AstrBot 原生 Agent 负责，插件只追加自己的提示词区块，不替换人格或其他插件的 system prompt。

## 快速开始

1. 在插件市场搜索 `jev决策综合插件` 安装，或在 AstrBot 目录执行 `git clone https://github.com/yiyinfaith/astrbot_plugin_decision.git data/plugins/astrbot_plugin_decision`。
2. 在 **AstrBot WebUI → 模型提供方** 配置 Decision/Jev Provider。地址、Key、模型、超时都在 AstrBot 管理，插件只选择 Provider。
3. 在 **插件 → 配置** 打开需要的三个总开关：「Tool/MCP/Skill/SubAgent 决策」「主动对话」「对话流增强」。
4. 打开插件详情页的「jev决策综合插件设置」页面调整详细规则，点击「保存全部设置」后立即生效；原生配置页的修改需热重载插件。

页面默认使用与 AstrBot 一致的简洁样式并跟随亮/暗主题；右上角「液态玻璃」开关可切换为 WebGL 液态玻璃特效（默认关闭，较耗性能，低配设备建议保持关闭）。

| 功能 | 说明 | 默认 |
| --- | --- | --- |

| 消息接话 | 未被唤醒时由 Jev 判断 Bot 是否适合插话 | 关（属「主动对话」） |
| 主动发起 | 按人格每日生成日程与穿搭，经 Jev 判断后主动联系指定会话 | 关（名单为空） |
| 多媒体生成 | 通过 aigen 以人格参考图 + 今日穿搭拍照、拍视频、生音频 | 拍照/视频工具开，音频关 |
| 人际网络 | 按人格维护人物、关系与共同经历，对话时注入关系上下文 | 关 |
| 对话流增强 | 输入：本地识别“谁在和谁说话”；输出：内置 OutputPro 发送管道 | 输入开，输出关 |
| 多模态理解 | 把图片、视频、音频、文件转成文字供主 LLM 使用 | 关 |

## 配置教程

### 原生配置页

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| Jev 模型提供商 | 空 | 选择 Decision/Jev Provider，留空使用 AstrBot 默认判断 Provider |
| 最大重试次数 | `1` | Jev 调用失败后的额外重试，`0` 为不重试 |
| 重试间隔 | `0` 秒 | 两次重试之间的等待 |
| 上下文上限 | `32000` Token | 主动对话超限时裁掉最旧历史；能力决策超限时自动分批并行 |
| 上下文消息数 / 字符数 | `8` / `6000` | 能力决策附带的历史消息条数与字符上限 |
| Tool/MCP/Skill/SubAgent 决策 | 开 | 能力决策总开关 |
| 主动对话 | 关 | 消息接话与主动发起的总开关 |
| 对话流增强 | 开 | 输入增强与输出增强的总开关 |

### 能力决策：判断与过滤

Tool、MCP、Skill、SubAgent 各有「判断」和「过滤」两个开关，开启判断的类别合并为一次 Jev 请求：

| 判断 | 过滤 | 交给主 LLM 的能力 | 推荐提示词 |
| --- | --- | --- | --- |
| 开 | 开 | Jev 选中 + 始终保留 | Jev 选中 + 始终推荐 |
| 开 | 关 | 全部 | Jev 选中 + 始终推荐 |
| 关 | 开 | 仅始终保留 | 仅始终推荐 |
| 关 | 关 | 全部 | 仅始终推荐 |

- 默认四类都判断，过滤 Tool、MCP、Skill，不过滤 SubAgent。判断阈值默认 `0.65`。
- 每个能力可勾「始终保留」（过滤时也保留）和「始终推荐给主 LLM」（须先勾始终保留）。AstrBot 内置工具和 `jev_decide` 默认始终保留。
- Skill 过滤只删除 AstrBot 生成的 `## Skills` 清单中未选中的条目，不改动其他 system prompt。
- **会话范围**：黑名单模式（默认）下名单内会话不做决策，名单为空即全部应用；白名单模式下只对名单内会话生效，名单为空即全部不应用。每行一个群号、私聊用户 ID 或完整 `unified_msg_origin`。
- **提示词**：「Jev 判断前提示词」只发给 Jev；「判断后注入主 LLM 的提示词」支持 `{tools}`、`{mcps}`、`{skills}`、`{subagents}` 占位符。
- Jev 失败时放行全部能力，手动「始终推荐」仍会注入，不影响正常聊天。

### 消息接话

收到未被唤醒的消息时，插件向 Jev 一次提问五个维度：是否在对 Bot 说话、插话是否自然、能否提供价值、时机、连续性（权重 `1.4 / 1.4 / 1.2 / 0.8 / 0.8`）。满足任一条件即回复：

- 加权综合分 ≥ 综合介入阈值；
- 直接指向分 ≥ 直接指向阈值，且自然介入分 ≥ 自然介入阈值。

已匹配的命令不进入判断；真实 @Bot、回复 Bot 或命中直接回复前缀时跳过 Jev，直接进入原生 Agent。AstrBot 原生 `active_reply` 开启时，插件自动停用自己的接话判断，避免重复回复。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 范围模式与名单 | 白名单 / 空 | 白名单为空 = 全部不接话；黑名单为空 = 全部接话 |
| 直接回复前缀 | `/`、`@` | 前缀从消息开头匹配；`@` 只认真实的 @Bot 节点 |
| 强制回复 | 开 | @Bot 或回复 Bot 时跳过 Jev，交给原生 Agent 回答，不占用接话冷却与次数 |
| 机器人昵称 | `AI\|助手` | 命中只算“可能被指向”，仍需 Jev 判断 |
| 综合介入 / 直接指向 / 自然介入阈值 | `0.68` / `0.70` / `0.85` | 调高则更少插话 |
| 判断间隔 | `3` 秒 | 间隔内消息只记录不判断；Jev 失败后间隔逐步拉长 |
| 回复冷却 | `60` 秒 | 两次主动接话的最短间隔 |
| 回复窗口 / 窗口最多回复 | `600` 秒 / `2` 次 | 时间窗口内的接话上限 |
| 历史消息数 / 最多会话数 | `12` / `500` | 发给 Jev 的历史规模与内存上限 |
| 观测超时 | `600` 秒 | 长时间无消息后重置会话状态 |
| 复读检测 | `3` 条 / `30` 秒 | 用于更新会话状态，不替代 Jev 判断 |
| 密集对话 | `30` 条 / `600` 秒 / `2` 人 | 同上 |
| 非文字消息是否进入判断 | 关 | 开启后纯图片/视频/音频/文件消息带媒体摘要参与判断 |

### 对话流增强

有独立的范围名单（默认黑名单、空 = 全部应用）。

- **输入增强 · 对话流分析**（默认开，窗口 `8` 条）：本地根据 @、引用、Bot 最近回复和发送者 ID 判断“谁在和谁说话”，结果并入接话判断，不增加 Jev 请求。
- **输出增强**（默认关）：内置 OutputPro 发送管道，按固定顺序执行图片外显与报错、拦截、艾特、清洗、替换、错字、文转语音、文转图片、引用与合并转发、撤回、分段，每步可单独开关。处理失败时保留原消息。若仍启用独立的 `astrbot_plugin_outputpro`，请只保留一个的输出增强。

### 主动发起

默认不会主动发送任何消息：私聊主动开、群聊主动关，但两类名单默认都是空白名单。

1. 开启原生「主动对话」；只要定时联系可在 WebUI 关闭「消息接话」。
2. 在目标会话发送 `/sid`，复制完整 UMO，如 `aiocqhttp:FriendMessage:123456`。
3. 在 **主动对话 → 主动发起** 打开「启用私聊主动」或「启用群聊主动」，把 UMO 填入对应名单（私聊名单只收 `FriendMessage`，群聊名单只收 `GroupMessage`）。
4. 选择日程模型（留空用 AstrBot 默认模型）和主动消息模型（留空用会话当前模型），保存。后台会生成今日日程并安排候选。
5. 在「今日生活与外貌」选择会话，点击「读取生活与外貌」确认结果；失败原因见「运行与操作结果」。

| 名单模式 | 名单非空 | 名单为空 |
| --- | --- | --- |
| 白名单（默认） | 只对名单内会话发起 | 全部不发起 |
| 黑名单 | 名单内会话不发起 | 已出现过的会话都可能发起 |

每个候选需通过开关、名单、免打扰、额度、冷却、未回应上限后，再由 Jev 判断「是否适合联系 / 话题价值 / 时机」三项，全部达到阈值才由原生 Agent 生成并发送。发送前若有新消息、人格变化或候选过期，未发送内容会被丢弃。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 主动发起阈值 | `0.7` | 三项都要达到 |
| 免打扰 | `23:00–07:00` | 起止相同表示不限制 |
| 候选有效期 / 后台并发 | `30` 分 / `2` | 有效期 1–120 分，并发 1–8 |
| 平台失败后暂停 | `30` 分 | 发送异常后暂停该平台候选 |
| 私聊：沉默 / 冷却 | `90–240` / `120` 分 | 从最后一条消息起计沉默时间 |
| 私聊：日预算 / LLM 加成 / 硬上限 | `1–3` / `2` / `5` | 预算是上限不是目标，硬上限最大 100 |
| 群聊：沉默 / 冷却 | `45–120` / `60` 分 | 群内持续聊天会重置沉默时间 |
| 群聊：日预算 / LLM 加成 / 硬上限 | `0–1` / `1` / `2` | |
| 连续未回应上限 | `3` | 达到后暂停；对方回复即清零 |
| 窗口最短沉默 / 时间抖动 | `20` / `15` 分 | 不打断热聊，避免每天同一时刻 |
| 睡眠偶发概率 | `0.08` | 偶尔生成起夜候选；「跳过免打扰」默认关，设 `0` 关闭 |
| 可打扰程度触发概率 | 禁止 `0` / 低 `0.25` / 普通 `0.7` / 高 `1` | 按当前日程忙闲决定候选是否触发 |
| 日程生成重试 | `2` | 模型输出 JSON 不合法时的修复次数，最多 5 |

其他分组（均在 WebUI，带说明）：

| 分组 | 内容 |
| --- | --- |
| 虚拟日程 / 提示词与模板 / 日程创意池 | 生成时间 `00:00`、历史参考 3 天、保留 14 天，可改系统词、模板与主题/心情/穿搭池 |
| 大时间表 | 长期阶段，支持自然语言草稿、JSON 导入与审批 |
| 日程图片渲染 | 日程/穿搭图主题、宽度（320–2400）、字体，失败回退文字 |
| 智能注入 | 按关键词把当前活动、穿搭、日程注入普通对话，上限 1600 字符 |
| 普通回复延迟 | 默认关；按日程忙闲公式延迟回复，@Bot、回复 Bot、命令不受影响 |
| 对话连续性 | 默认开；跟进未结束话题、按互动质量调节联系 |
| 自动联系频率 | 默认关；开启后以目标间隔取代随机预算，可让用户通过工具调频 |
| 拟人化节奏 | 默认开；话题轮换、关系阶段、群聊对象感保护 |
| 时间承诺 | 默认关；记录约定并在到点时联系，每日明确提醒上限 3 |
| 日程思考 | 默认关；为日程生成想法，择机分享 |
| 主动消息分段 | 默认开；原文超过 150 字时整条发送不分段 |

### aigen 多媒体

1. 安装并配置好 [astrbot_plugin_aigen](https://github.com/yiyinfaith/astrbot_plugin_aigen)；`send_voice` 需要 aigen 提供 `generate_audio`。模型、Key 和计费都由 aigen 负责。
2. 在 **主动发起 → 外貌参考图（按人格）** 为人格上传参考图：PNG/JPEG/WebP，每张 ≤ 8MB、≤ 2500 万像素，每人格最多 5 张。
3. 保持每日穿搭生成开启。提示词组合参考图、外貌补充描述、今日穿搭、当前活动和拍摄场景；没有今日穿搭时，按「无今日穿搭时沿用参考图穿搭」（默认开）决定是否沿用参考图服装。
4. 在 **多媒体生成** 打开对应工具开关，并在能力决策中保留这些工具。

```text
take_photo(scene="坐在书店窗边看书", subject="self", count=1)
take_video(scene="在河畔散步，向镜头挥手", subject="scene")
send_voice(text="今天路过一家很好吃的面包店", style="轻快地分享")
```

`subject`：`self`（自己，默认）、`other`（别人）、`scene`（景色）、`object`（物品）、`screenshot`（手机截图 / 录屏）。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 照片比例 / 视频比例 / 视频时长 | `3:4` / `9:16` / `5` 秒 | 时长 1–120 秒 |
| 生成冷却 | `60` 秒 | 0–3600 |
| 每会话每日生成上限 | `5` | 按实际张数/段数计，不是金额 |
| 音频模式 / 音色 ID | `朗读` / 空 | 模式可选 `朗读`、`提示词` |
| 主动发起附带照片/视频/音频概率 | `0` / `0` / `0` | 各自独立掷骰，命中多种时按概率加权只选一种 |
| 各类数量上下限 | `1–1` | 0–10，工具会再次钳制模型给的 `count` |
| 主动发起计费账户 | `fixed` | 必须同时填写下面两项，否则拒绝主动付费任务 |
| 固定账户平台名 / 用户 ID | 空 | aigen 账本中的账户，例如 `aiocqhttp` + `123456` |

> 为什么要固定计费账户：主动发起没有真实发送者，aigen 会把私聊对象或群号当作扣费账户。普通聊天中的工具调用仍按 aigen 原规则由发送者付费。

| 关系注入位置 | `system_prompt` | 或 `user_content` |

### 多模态理解

位于 **对话流增强 → 输入增强**，默认全部关闭。模型从 AstrBot 已配置的 Provider 中选择（一个默认模型，图片/视频/音频/文件可单独覆盖），不需要重复填写 Key。

- **自动理解**：开启总开关、媒体类型开关并选好模型后，收到媒体即在后台理解并缓存，按需注入后续请求；不会唤醒 Bot。默认白名单且为空，需填入会话。
- **主动工具**：开启工具开关后，模型可调用 `understand_*` 工具，不受自动理解名单限制。
- 只支持图片的模型也能理解视频（抽帧）和文件（提取文本）；动图会拆帧，避免上游拒收 GIF。

| 策略 | 选项 |
| --- | --- |
| 视频处理 | 自动（默认：Gemini 短片直传原视频，其余抽帧）/ 优先原生 / 强制抽帧 |
| OCR | 自动（默认）/ 本地优先 / 视觉模型优先 / 仅本地 |

常用上限：文件 `40` MB、文件文本 `12000` 字符、注入 `1200` 字符、单条消息自动理解 `4` 个、每分钟 `12` 个、短视频 `60` 秒、视频/音频最长 `600` 秒、超时 `180` 秒、并发 `2`、缓存 `12` 小时。

本地 OCR 为可选依赖：

```bash
apt install tesseract-ocr tesseract-ocr-chi-sim && pip install pytesseract   # Tesseract
pip install paddleocr paddlepaddle                                          # 或 PaddleOCR
```

| `data/plugin_data/astrbot_plugin_decision/virtual_life/` | 日程、阶段、计数、人格参考图 |
| `data/plugin_data/astrbot_plugin_decision/personal_network/` | 人际网络数据库、头像、导出 |

| 现象 | 检查 |
| --- | --- |
| 主 LLM 仍看到全部工具 | 能力决策总开关、该类别的判断与过滤开关、会话范围 |
| 有判断但没推荐 | 判断阈值、Jev 返回、注入提示词中的占位符 |
| 不接话 / 不主动发起 | 「主动对话」总开关、名单模式（白名单为空 = 全部不生效）、AstrBot 原生 `active_reply` 是否开启 |
| 主动发起不带图片/视频/音频 | 多媒体总开关、类型开关、概率是否大于 `0`（概率只是掷骰） |
| `send_voice` 只返回说明 | aigen 是否提供 `generate_audio`，「启用生音频工具」是否打开 |
| Jev 请求失败 | `/decision test`，检查 Decision Provider 是否可用 |
| 保存后设置消失 | `data/config` 是否可写 |
